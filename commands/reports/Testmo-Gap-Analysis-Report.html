Bottom line. Two unblockers clear most agent failures: (1) concrete fixtures (Field:Value / named load — themes A, G, H, I), and (2) atomic steps + assertable Expected (themes B, C, E, F, J). Themes D–J are not optional extras — login, nav language, role switch, cross-app handoff, EDI oracles, and View Load vs View Billing surface naming regularly block generation even when some data exists.
